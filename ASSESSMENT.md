# BeyondClass maths assessment

assessment.html is self-contained. It contains 100 original questions across five topic areas and five broad difficulty bands; each attempt uses at most 20 items over 15 minutes. Adaptation and report thresholds are transparent in the parent report. Results are informal screening evidence, not IQ, diagnosis, grade, or a measured age level.

The downloadable local copy has delivery disabled. The deployed copy must keep delivery disabled until Netlify form detection is enabled and the maths-assessment form has an email notification to hellobeyondclass@gmail.com. Enable CONFIG.deliveryEnabled only after those settings are verified. A successful HTTP submission confirms acceptance by the site, not delivery to the email inbox. Verify a labelled synthetic submission in Netlify and ask the owner to confirm receipt.

Parent contact email is collected but is not a notification recipient. No API secrets are placed in the HTML. Reports include personal details and are submitted only after parent/tutor permission. Session storage lasts for the tab session with a 24-hour restore expiry. Clear the session on shared devices.

Netlify build processing is enabled for form detection, with script/style minification disabled to preserve CSP hashes. The existing private inbox functions are unchanged.

Change the BANK array to revise questions; review explanations and test all routes after changes. Assessment answers are in the browser source; this is a low-stakes learning tool, not a secure exam.
